# 组件映射与冲突

按以下顺序选择实现：

1. `exact`: Code Connect精确匹配并验证源码。
2. `semantic`: 复用语义与行为匹配的现有组件。
3. `compose`: 组合现有组件。
4. `extend`: 局部扩展且检查影响面。
5. `create`: 没有合理复用途径时新增。
6. `blocked`: 关键冲突无法安全解决。

`component-map.json` 只记录实际使用的映射，不要求为整个Figma文件建立目录。`confidence`不能代替源码验证。

冲突等级：

- P3：非关键视觉偏差，可修复并记录。
- P2：缺少组件能力，修复后重点审查。
- P1：设计与业务、兼容性或已批准方案冲突，返回方案审查。
- P0：安全、合规或未授权破坏性修改，立即阻塞。

P0/P1只有 `resolved` 或有明确授权的 `approved` 状态才允许通过门禁。
